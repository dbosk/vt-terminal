\section{Search and verification protocol}
\label{app:protocol}

This appendix documents the literature searches behind the references, for
reproducibility, following the protocol of the companion paper
\autocite[App.~literature protocol]{VTProgMisconceptions}: every reference
was found by a recorded query, read at least at abstract level, and
recorded with a provenance block (claim, query, selection rationale,
verbatim supporting quote, verification level) directly above its entry in
\texttt{misconceptions.bib}.

\subsection{Phase one: seed round (2026-07-18)}

The seed round was a claim-driven search conducted with the
\texttt{scholar} tool against DBLP, OpenAlex, and Semantic Scholar
(Semantic Scholar was rate-limited during part of the session), with
abstracts fetched via the OpenAlex API and full texts from open repository
copies.
Broad queries (e.g.\ \enquote{students mental models file system}) were
dominated by irrelevant medical and machine-learning hits and were replaced
by phrase and author-anchored queries.
The queries whose results were retained:

\begin{itemize}
  \item \texttt{scholar search "shell tutor" -p dblp}
  \item \texttt{scholar search '"command line" novice' -p openalex}
  \item \texttt{scholar search "Doane unix experts strategies" -p openalex -p dblp}
  \item \texttt{scholar search "navigation search file retrieval preference" -p openalex}
  \item \texttt{scholar search "Bergman Whittaker file retrieval" -p openalex}
  \item \texttt{scholar search "folder metaphor cloud" -p dblp -p openalex}
  \item \texttt{scholar search "finding reminding file organization" -p dblp}
  \item \texttt{scholar search "black box inside glass box presenting computing concepts" -p openalex -p dblp}
  \item \texttt{scholar search "Sorva notional machines introductory programming" -p dblp -p openalex}
  \item \texttt{scholar search "Ben-Ari constructivism" -p dblp}
  \item \texttt{scholar search "difficulties of learning to program du Boulay" -p openalex}
  \item \texttt{scholar search '"variation theory" computer programming' -p openalex}
\end{itemize}

Discarded as unverifiable or redundant in this round: Norman's 1981
\emph{The trouble with Unix} (no verifiable source located); the use of
journalism \autocite{Chin2021FileNotFound} as evidence (retained only as a
flagged anecdote).
Not yet verified at full text (tracked in the course repository's issues
\#124--\#126): \autocite{DuBoulay1981BlackBox},
\autocite{BenAri1998Constructivism}, \autocite{Dillon2012MentalModels}.

\subsection{Phase two: systematic round}

The systematic round (2026-07-18) targeted the four gaps the seed round left
open: command-line and shell misconceptions in CS-education venues; learners'
(as opposed to professional users') file-system mental models; SSH and
remote-shell learning; and pipeline-construction difficulty.
It was run with the \texttt{scholar} tool against OpenAlex.
Two intended providers were unavailable: DBLP returned zero results for every
query in this session---including the seed round's known-good
\texttt{scholar search "shell tutor" -p dblp}---and Semantic Scholar's search
endpoint was rate-limited, usable only for DOI-keyed abstract lookups.
OpenAlex therefore carried the round; abstracts were read through the
OpenAlex and Semantic Scholar APIs.
Each retained reference was read at least at abstract level and recorded with
a provenance block in \texttt{misconceptions.bib}.

Both keyword and research-question-driven queries were used.
The research-question queries were generated with \texttt{scholar rq} from the
paper's research questions, one per gap:

\begin{itemize}
  \item \texttt{scholar rq "What misconceptions and difficulties do learners
    have with the Unix command line and shell?" -p openalex}
  \item \texttt{scholar rq "How do students or novice users understand
    hierarchical file systems, directories and paths?" -p openalex}
  \item \texttt{scholar rq "How do learners understand SSH and remote shell
    access to another machine?" -p openalex}
  \item \texttt{scholar rq "Why do users find it difficult to compose Unix
    commands with pipes and build shell pipelines?" -p openalex}
\end{itemize}

\texttt{scholar rq} generated Boolean queries for each (e.g.\ for the shell
question, \enquote{(Unix command line OR shell OR bash OR terminal) AND
(learners OR students OR novices OR beginners) AND (misconceptions OR
difficulties OR errors OR challenges OR mental models OR misunderstandings)}),
but its large paged fetch was repeatedly rate-limited by OpenAlex; the same
coverage was therefore obtained through the smaller phrase queries below,
which mirror the generated terms.
The keyword and phrase queries, grouped by gap:

\begin{itemize}
  \item \emph{Command line and shell.}
    \texttt{scholar search "command line interface novice programmers" -p
    openalex}; \texttt{scholar search '"command line" students learning
    interface' -p openalex}; \texttt{scholar search 'shell OR "command line"
    students misconceptions difficulties learning' -p openalex}.
  \item \emph{File system.}
    \texttt{scholar search "students mental model file system directory" -p
    openalex}; \texttt{scholar search '"directory structure" students
    understanding files folders' -p openalex}; \texttt{scholar search "novice
    users hierarchical file system directories mental models understanding"
    -p openalex}.
  \item \emph{Remote shell.}
    \texttt{scholar search "SSH remote access students learning" -p openalex};
    \texttt{scholar search '"secure shell" OR "remote login" learning students
    education' -p openalex}; \texttt{scholar search 'SSH OR "secure shell" OR
    "remote shell" learners understanding misconceptions' -p openalex}.
  \item \emph{Composition.}
    \texttt{scholar search "Unix pipe pipeline composition difficulty" -p
    openalex}; \texttt{scholar search 'shell pipe OR pipeline composition
    difficulty users novice construct' -p openalex}.
\end{itemize}

Screening kept a result only if it concerned \emph{learners or novices} and
one of the four objectives, at a level of description useful for the aspect
analysis; systems papers (file-system benchmarks, kernel internals) and the
large volumes of unrelated medical, machine-learning and health-education
hits that the broad queries returned were discarded.
Two references were retained.
The command-line queries surfaced a command-logging toolset for hands-on
cybersecurity training, whose analysis of the shell commands students run
reports \enquote{different solution patterns, used tools, and misconceptions
of students} \autocite{Svabensky2021ShellCommands}---a second corpus of
student shell behaviour alongside the Shell Tutor, cited in
\cref{sec:shell,sec:related}.
The same queries surfaced a controlled study of how error-message
presentation shapes novice behaviour \autocite{Karvelas2020ErrorMessages},
retained (with its scope---the BlueJ programming environment, not the
shell---recorded in its provenance block) as background for treating the
shell's textual feedback as a critical aspect (\cref{sec:shell}).
One promising command-line title, \emph{Automated testing of Unix
command-line and scripting skills} (ITHET 2006), was \emph{not} retained: no
abstract was accessible through any provider this session, and the protocol
forbids citing what has not been read.

For the three remaining gaps the round is a confirmation rather than a
harvest.
The file-system queries returned only professional-user or systems work and
no study of how learners build a mental model of the directory tree; the
remote-shell queries returned nothing on SSH or remote-shell learning; and
the composition queries returned no later replication or CS-education study of
pipeline-construction difficulty, leaving \textcite{Doane1992UnixPrompts} the
sole source.
These empty results substantiate the gaps that \cref{sec:filesystem,sec:ssh}
and \cref{sec:composition} fill with aspect analyses grounded in course
observations rather than in a learner-focused literature that does not yet
exist.

\subsection{Extended-database round (2026-07-19)}

The rounds above searched only the keyless providers (DBLP, OpenAlex,
Semantic Scholar); Web of Science, Scopus and IEEE~Xplore were configured
but unused.
This round repeated the gap-critical queries across all providers:
\begin{itemize}
  \item \texttt{scholar search "command line interface students
    misconceptions" -p wos -p scopus -p ieee} --- retained
    \autocite{Salerno2026ToolInstallation} (novice tool-installation
    challenges, EMSE) and identified \emph{The Linux Luminarium}
    (Shoshitaishvili, Doup\'e \& Nelson, SIGCSE~TS 2026, DOI
    10.1145/3770762.3772655, CC-BY): a Linux-teaching curriculum
    explicitly designed around eliminating manual-setup barriers.
    % TODO: The Luminarium's full text is open (CC-BY) but ACM blocked
    % automated retrieval; read and, if it documents learner
    % difficulties, retain with provenance.
  \item \texttt{scholar search "unix shell terminal teaching novices" -p
    wos -p scopus -p ieee} --- teaching interventions only, no
    misconception study.
  \item \texttt{scholar search "SSH remote access teaching students" -p
    wos -p scopus -p ieee} --- remote-lab platform papers only: the
    SSH-learning gap \emph{holds across Web of Science, Scopus and IEEE
    Xplore as well}.
  \item \texttt{scholar search "file system folder hierarchy students
    mental model" -p wos -p scopus} --- nothing on-topic: the
    learner-file-system gap likewise holds across the added databases.
\end{itemize}
Natural-language queries rank noticeably worse in Web of Science and
Scopus than in the CS-specific indexes; a future round should use their
field-tagged syntax (\texttt{scholar syntax}).
